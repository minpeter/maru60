# Study-only alternate MX hot-swap composites

Generated by `../../tools/merged_hole_candidates.py` from actual ai03 MX_V2
footprints at the vendored revision. Derivative geometry retains the upstream
MIT license and copyright in `../third_party/MX_V2/LICENSE`.

These are **not approved production footprints**. Native isolated socket DRC
passes, but PCB-mount stabilizer holes, 3D switch/plate/keycap fit and LED layout
are separate gates. See `../alternative-collision-report.md` and the JSON reports.
Normal and alternate switches are mutually exclusive assemblies, even though all
socket sites may be fabricated. Never populate incompatible switch combinations.

Composite electrical pad pairs:1/2 normal,3/4 first alternate,5/6 second alternate
when present. Origin: normal switch center. Place on B.Cu as documented in the
study generator; source files are library-normalized F.Cu. Overall Maru60 hardware
license remains the owner's pending choice.

## Mill-Max Backspace candidate (2026-11-02)

`MX_Study_Backspace_MillMax3305_2U_or_1U_1U_PCBStab` retains MIT ai03 locating-hole
geometry and uses original receptacle pad geometry derived from the Mill-Max3305
manufacturer dimensions. Unlike the earlier Kailh-only Backspace candidate,
it passes isolated DRC with PCB-stabilizer holes included. This changes assembly
to six solder-in receptacles and is not selected for the main PCB automatically.
See `../alternative-socket-decision.md` for exact fit, plating, tolerance and
selected-switch/stabilizer coupon gates.
