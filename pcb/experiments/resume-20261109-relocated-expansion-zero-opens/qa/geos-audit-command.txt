GEOS + exact-rational inner-plane replay for the relocated-expansion zero-open checkpoint
=========================================================================================

Run from the repository root. The audit writes exact-native-plane-inputs.json
(about 80 MB) into the output directory; the GEOS replay reads that file and
writes geos-audit.json and geos-rational-witnesses.json into the same
directory. Use a fresh directory under .omo/evidence/ or build/; do not write
into the published qa/ directory.

Step 1 - native audit (pcbnew, KiCad 9.0.2 container):

    tools/run_kicad9.sh python3 pcb/tools/audit_relocated_zero_opens.py \
      --candidate-board pcb/experiments/resume-20261109-relocated-expansion-zero-opens/pcb/maru60.kicad_pcb \
      --candidate-material pcb/experiments/resume-20261109-relocated-expansion-zero-opens/qa/material-graph.json.gz \
      --out-dir .omo/evidence/relocated0-audit-new

Step 2 - independent GEOS replay (repository virtual environment):

    .venv/bin/python pcb/tools/geos_witness_zero_opens.py \
      --qa-dir .omo/evidence/relocated0-audit-new

The promoted scripts default their source/candidate paths to the tracked
checkpoints, so the explicit --candidate-* arguments above are optional; they
are shown to make the inputs unambiguous. The source checkpoint defaults to
pcb/experiments/resume-20261109-header25-u13-contact-repair.
