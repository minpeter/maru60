Native CAD replay for the relocated-expansion zero-open checkpoint
==================================================================

Run from the repository root. The output directory must be new and separate
from the checkpoint; use an ignored path under .omo/evidence/ or build/.

    tools/run_kicad9.sh python3 tools/check_pcb_native.py \
      --checkpoint pcb/experiments/resume-20261109-relocated-expansion-zero-opens \
      --expected-opens 0 \
      --expected-warnings 0 \
      --output .omo/evidence/relocated0-native-new \
      --material

The archived qa/native/*.log files were produced by the same checker before
--expected-warnings existed. Their "Saved ... to /workspace/.omo/evidence/
pcb-routing-20261109/manual/repair2-native/..." lines record the original
container path; the command above writes the same reports to a fresh host
directory. The checker now records its argv and cwd in RESULT.json.
