# Standalone Rule 60 V3 wrist rest

The standalone two-piece honeycomb wrist rest uses integral sliding dovetails,
with no screws, magnets or separate connectors. Its current revision is the
tight-fit male joint with the unchanged v9 receiver. The owner's coupon test
does not establish full-body strength or long-term retention.

Published files stay in [`models/rule60-v3-wrist-rest/`](../models/rule60-v3-wrist-rest/).
Run the standalone `build.py`, `verify.py` and `export.py` commands from the
repository root as documented in the fabrication reference. The housing
pipeline does not build this separate model. `export.py` refreshes its published
models and evidence; omit export when exploring geometry locally.
